# Contributing to Census 2027 Digital Portal

Thank you for your interest in contributing to India's First Digital Census project!

## Development Workflow
1. **Fork & Clone**: Fork the repository and clone it locally.
2. **Branching**: Create a feature branch (`git checkout -b feature/amazing-feature`).
3. **Dependencies**: Run `npm install` to install required dependencies.
4. **Code Quality**: Follow modular MVC structure under `src/` and WCAG AA guidelines under `public/`.
5. **Testing**: Run `npm test` to ensure all 8 integration tests pass.
6. **Submit PR**: Push to your branch and open a Pull Request using the provided PR template.
